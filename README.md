# Эмулятор UNIX-подобной командной строки (VFS Shell)

Данный проект представляет собой консольный эмулятор (CLI) командной строки UNIX, разработанный в рамках курса «Конфигурационное управление». Эмулятор работает с виртуальной файловой системой (VFS) в оперативной памяти на базе CSV-файла и поддерживает чтение зашифрованных в Base64 данных.

## 🛠️ Системные требования и зависимости
* Операционная система: macOS / Linux / Windows
* Язык реализации: **Python 3.10+**
* Встроенные библиотеки: `sys`, `argparse`, `configparser`, `csv`, `base64`

## ⚙️ Параметры конфигурации запуска
Эмулятор поддерживает гибкую настройку через конфигурационный INI-файл (`config.ini`) со следующими параметрами:
* `vfs_path` — путь к CSV-таблице виртуальной файловой системы;
* `start_script` — путь к стартовому скрипту автоматического выполнения команд.

*Логика приоритетов:* значения из INI-файла имеют высший приоритет над аргументами командной строки.

## 🚀 Инструкция по запуску
Для запуска эмулятора на вашем устройстве выполните команду:
```bash
python3 emulator.py
```

## 💻 Поддерживаемые UNIX-команды
1. `ls` — просмотр содержимого текущей виртуальной директории;
2. `cd [путь]` — смена текущего рабочего каталога (поддерживает относительные переходы `.` и `..`);
3. `cat [файл]` — чтение файла с автоматическим раскодированием данных из формата Base64;
4. `rev [файл]` — вывод текстового содержимого файла с реверсом (переворотом) каждой строки задом наперед;
5. `conf-dump` — служебная команда вывода текущих параметров инициализации эмулятора;
6. `exit` — корректное завершение работы CLI-сессии.
